## 重现

```text
npm ci
npm run build
npm test
npm run doctor
```

浏览器检查额外需要 Chromium。可以安装 Playwright 管理的浏览器后执行 `npm run test:browser`，或通过 `CHROMIUM_PATH` 指向已有 Chromium。本次 Linux 验证环境使用 `/usr/bin/chromium`。浏览器脚本会创建并清理临时项目与数据库；截图写入被 Git 忽略的 `artifacts/`。
